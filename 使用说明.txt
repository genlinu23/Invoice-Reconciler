====================================
    发票整理工具 - 使用说明
====================================

【功能】
自动提取发票信息，按金额和类型重命名文件

【快速开始】
1. 配置 .env 文件中的 API 密钥
2. 运行：python app.py
3. 输入发票文件夹路径
4. 等待处理完成

【命令行使用】
python app.py                          # 交互式输入
python app.py "发票文件夹"              # 指定输入文件夹
python app.py "发票文件夹" "输出文件夹" # 指定输入和输出

【输出格式】
金额_类型_日期.扩展名
例如：168.01_餐饮_20240115.pdf

【支持格式】
JPG, PNG, PDF

【发票类型】
餐饮、交通、住宿、其他

【统计信息】
处理完成后会生成 statistics.json，包含：
- 总金额
- 各类型统计
- 成功/失败数量
