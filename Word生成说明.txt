====================================
  Word文档生成功能说明
====================================

【功能】
将整理后的发票生成Word文档，每页显示2个发票

【使用方法】
python generate_word.py <输出文件夹路径> [Word文件名]

【示例】
# 基本用法（默认文件名：发票汇总.docx）
python generate_word.py "C:\Users\17193\Desktop\发票整理工具\发票\output"

# 指定文件名
python generate_word.py "C:\Users\17193\Desktop\发票整理工具\发票\output" "发票汇总报告.docx"

【Word文档内容】
1. 封面
   - 标题：发票汇总报告
   - 生成日期

2. 统计表格
   - 发票总数
   - 总金额
   - 分类统计
   - 金额分布

3. 发票明细
   - 每页显示2个发票
   - 每个发票显示：
     * 序号
     * 发票图片
     * 金额、类型、日期

【文档格式】
- 页面：A4纸
- 布局：每页2个发票
- 图片宽度：5.5英寸
- 自动分页

【输出位置】
Word文档保存在指定的输出文件夹中

【注意事项】
1. 需要先运行发票处理程序生成发票文件
2. 确保output文件夹中有statistics.json文件
3. 支持PDF、JPG、PNG格式
4. PDF会自动转换为图片插入
